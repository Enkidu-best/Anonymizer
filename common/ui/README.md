## Увеличение картинки (`web/zoom.js`)

Эталон - «Понятный документ» `zoomImage` («Сравнить стили»: щелчок по странице - во весь экран).

| Действие | Что происходит |
|---|---|
| щелчок по картинке | крупно поверх окна на тёмном фоне, подпись и «2 из 5» |
| ← / → и кнопки ‹ › | соседние картинки (по кругу) |
| колесо | масштаб 1-5×; двойной щелчок - 100 % |
| Esc, щелчок мимо картинки, × | закрыть; фокус возвращается туда, где был |
| Tab | не уходит из окна |

Подписи RU / EN - по `lang` страницы. Стили встроены (не зависят от токенов программы): белый лист под картинкой,
кнопки и подписи - контраст ≥ 4,5 : 1 (проверено `common/a11y`).

```html
<script src="/common/ui/zoom.js"></script>
<script>
  ZoomImage.bind("#gallery", "img.zoomable");            // все такие картинки в контейнере - одним просмотром
  ZoomImage.open([{src: "/p1.png", name: "Стр. 1"}, …], 0); // или вручную
</script>
```

Копия - `scripts/sync_common.sh ui <проект>`; сервер раздаёт `common/ui/web/` по адресу `/common/ui/`.

## Строка состояния модели (`web/model-status.js`, стандарт 2.1)

Эталон - Anonymizer 4.0. Одна строка в шапке, одни слова и цвета во всех программах:

| `state` | Слова (RU / EN) | Цвет |
|---|---|---|
| `ready` | «Модель готова» / Model ready | зелёный `--ok` |
| `working` | «Работает» (+ « · 40 %») / Working | синий `--info`, иначе `--accent`; точка мигает |
| `loading` | «Модель загружается» (+ ход) / Model loading | серый `--faint`; точка мигает |
| `queued` | «Занята «<программа>» - в очереди» / Busy: «…» - queued | жёлтый `--warn` |
| `off` | «Нет модели» / No model | серый `--faint` |
| `error` | «Ошибка модели» / Model error; щелчок - «Что случилось» и «Повторить» | красный `--bad` |

```html
<script src="/common/ui/model-status.js"></script>
<script>
  ModelStatus.mount("#model", {onClick: подробности, onRetry: повторить});   // элемент шапки
  ModelStatus.set({state: "working", text: "Работает: файл 1 из 3", progress: 40});
  ModelStatus.set({state: "error", detail: "Ollama не отвечает"});           // щелчок - что случилось и «Повторить»
</script>
```

`text` - свои слова программы (цвет и смысл - от `state`). `data-state` на элементе - для проверок. После смены языка окна - `ModelStatus.refresh()`.

## Меню значками в узком окне (`web/narrow-menu.js`, стандарт 1.6)

Эталон - Anonymizer 4.0: до 1100 px (и в 900 px) меню слева не уезжает, а сворачивается в значки, у значка - подсказка с названием пункта.

```html
<script src="/common/ui/narrow-menu.js"></script>
<script>NarrowMenu.bind("#side", {cls: "collapsed", items: ".mi", keep: () => свёрнуто_кнопкой});</script>
```

`cls` - класс «меню значками» программы (подписи прячет её CSS); `keep()` - человек сам свернул меню: в широком окне оно остаётся свёрнутым. Пока окно узкое, на `<html>` висит класс `ui-narrow`.
