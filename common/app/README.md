# app - сборка .app одним способом (стандарт 6.2)

Версия 1.0.0 (24.10.2026, «Порядок 02», п. 1). Эталон - Interview Coach `desktop/build_app.sh`.

## Зачем

Если исполняемый файл пакета - bash-скрипт, macOS считает обращающейся к папке «Рабочий стол» программой `/bin/bash`,
вопрос о доступе не показывает и молча отказывает: пакет «не открывается» (Interview Coach 23.10, «Видеокарта.app»
24.10). Поэтому исполняемый файл - маленькая программа на C, логика - в `launcher.sh` программы (правится без
пересборки). При первом запуске macOS спрашивает доступ к «Рабочему столу» от имени самого приложения - один раз.

## Что лежит

| файл | что делает |
|---|---|
| `launcher.c` | исполняемый файл пакета: находит `launcher.sh` (путь задаёт сборщик), проверяет доступ к папке (нет - окно с подсказкой, где разрешить), запускает скрипт и ждёт; журнал - `~/Library/Logs/<Имя>.log` |
| `build_app.sh` | сборка: clang arm64 с именем и путём к скрипту, `Info.plist`, значок (`.icns` или `.png` → `.icns` через `sips` и `iconutil`), подпись ad-hoc, регистрация в системе (`lsregister`); прежняя сборка - в корзину (`~/.Trash`), не безвозвратно |

## Как собрать

```
bash "_общие модули/app/build_app.sh" --name "Видеокарта" --id local.andrey.gpu-page \
    --dest "_общие модули/lock/tools" --script "_общие модули/lock/tools/gpu_launcher.sh" \
    --icon "_общие модули/lock/tools/icon/gpu-icon-1024.png" --version 1.3.0 --ui-element
```

`--ui-element` - без значка в Dock (служебная программа), `--applications` - ссылка в «Программах». Скрипт внутри
`--dest` записывается относительным путём - папку можно перенести.

**Собирать один раз.** Пересборка меняет подпись: macOS снова спросит доступ к папкам и микрофону.

Проверка после сборки (правило 10 - браузер Андрея не открывать):
`open --env GPU_PAGE_NO_OPEN=1 "<…>/Видеокарта.app"` → процесс запустился, `/api/ping` отвечает, страницу открывает
Playwright. При самом первом запуске программа ждёт ответа на вопрос macOS о доступе к «Рабочему столу».
