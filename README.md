# Anonymizer — локальное обезличивание документов

Готовит документы к отправке во внешнюю нейросеть: находит персональные данные, банковскую и коммерческую тайну и заменяет их метками вида `[FIO_1]`, `ООО «[YUL_2]»`, `[INN_3]`. Ответ нейросети загружается обратно — метки заменяются исходными значениями.

**Всё работает только на компьютере.** Нет внешних API, телеметрии, облака. Модели скачиваются один раз при установке.

## Запуск на Mac

`Anonymizer.app` в папке проекта (ярлык - «_Программы - быстрый запуск») поднимает сервер на `127.0.0.1:8070` и
открывает окно Chrome в режиме приложения. Собирается общим сборщиком: `./build_macos.sh` (исполняемый файл -
программа на C, логика - `desktop/launcher.sh`). При первом запуске macOS спросит доступ к «Рабочему столу» - один раз.

Данные (база, файлы сессий, `settings.json`) - `~/Library/Application Support/Anonymizer`, журнал - `~/Library/Logs/Anonymizer/`,
и при запуске из исходников тоже. Сессия удаляется целиком через срок из Настроек (7 / 30 / 90 дней, по умолчанию 30)
или сразу кнопкой - без корзины. Windows: `build_windows.bat` (сборка 3.x, не обновляется - решение 24.10).

## Запуск из исходников

```bash
python3.12 -m venv .venv312
.venv312/bin/pip install -r requirements-dev.txt
./start.sh                      # сервер :8070 и окно; NO_BROWSER=1 - без окна; ./stop.sh, ./status.sh
```

## Что обрабатывается

| Формат | Что проверяется |
|---|---|
| DOCX, DOC, ODT | текст, таблицы, надписи, колонтитулы, сноски, комментарии, исправления (принимаются), гиперссылки, свойства файла (автор очищается) |
| PPTX | слайды, заметки, диаграммы |
| XLSX | ячейки (в т.ч. числа — ИНН, телефоны), комментарии, названия листов, колонтитулы, свойства |
| PDF | PDF с текстом превращается в Word (DOCX) и обрабатывается как Word — можно править, в просмотре работает «исходный текст»; по желанию сохраняется и обезличенный PDF (меню «⋯» → «Настройки»). Сканы — распознавание текста (macOS) и закраска чёрным, остаются PDF |
| RTF | текст с кириллицей в любой кодировке |
| JPG, PNG, HEIC, TIFF | распознавание текста (macOS), закраска найденного, удаление EXIF/GPS |
| TXT | текст |

Имя выходного файла тоже обезличивается: `Договор_Иванов.docx` → `Договор [FIO_1].docx`; файл с возвращёнными данными - `… (данные возвращены).docx`.

**Что находит:** ФИО во всех падежах и формах (инициалы, заглавные, «оглы», латиница), организации (ОПФ остаётся в тексте), ИНН, ОГРН/ОГРНИП, КПП, счета, БИК, карты, IBAN, SWIFT, СНИЛС, паспорт (только серия, номер, кем выдан, код подразделения), водительское удостоверение, телефоны, e-mail, мессенджеры, даты и места рождения, адреса, кадастровые номера, госномера, VIN, ОКПО, полисы ОМС.

**Один человек — одна метка.** «Иванов Пётр Сергеевич», «Иванову П.С.», «Иванов» в подписи — всё `[FIO_1]`. При обратной замене каждое место получает свою исходную форму.

**Проверка утечек.** После обработки готовый файл читается заново: если в нём осталось что-то подозрительное, это видно в списке файлов.

## Локальная нейросеть и видеокарта

Один режим «Обезличить» (правила, модель распознавания имён, проверка утечек). Галочка «Использовать нейросеть»
(Настройки → Дополнительно, по умолчанию выключена) добавляет проверку найденного и подбор падежа локальной моделью (Ollama) -
под общей очередью видеокарты с другими программами
этого компьютера (общий модуль `common/lock`). Если видеокарта занята другой программой, появится окно «Видеокарта занята»:
подождать очереди, запустить сейчас, считать на процессоре (очень медленно, с прогнозом времени) или отменить.

## Работа с внешней нейросетью

1. Обработайте документ, скачайте результат.
2. Нажмите **«Скопировать инструкцию для нейросети»** и вставьте её в чат перед документом - нейросеть не будет менять метки.
3. «Вернуть данные» → выберите сессию → вставьте ответ текстом («Текст») или загрузите файл («Файл»).
4. Значения, которые нужно маскировать или не маскировать во всех сессиях, - в разделе «Словарь».

Метки распознаются, даже если нейросеть их немного изменила: `FIO_1`, `[FIO 1]`, `[fio-1]`, `[ФИО_1]`. В новом тексте нейросети имя ставится в нужный падеж автоматически (такие места подсвечены жёлтым), организация — в кавычках и с ОПФ, если её нет рядом.
