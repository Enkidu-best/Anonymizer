# 🔐 Anonymizer — Локальная защита персональных данных

Инструмент для анонимизации и деанонимизации персональных данных в документах.
Работает **полностью локально** — данные не покидают компьютер (соответствие ФЗ-152).

---

## Что обнаруживается

| Тип | Токен | Метод |
|-----|-------|-------|
| ФИО (все падежи) | `FIO_1` | Natasha NER |
| Юрлица / организации | `YUL_1` | Natasha NER |
| ИНН (10 или 12 цифр) | `INN_1` | Regex |
| ОГРН / ОГРНИП | `OGRN_1` | Regex |
| КПП | `KPP_1` | Regex |
| Расчётный счёт | `RS_1` | Regex |
| Корреспондентский счёт | `KS_1` | Regex |
| БИК | `BIK_1` | Regex |
| СНИЛС | `SNILS_1` | Regex |
| Паспорт (серия + номер) | `PASSPORT_1` | Regex |
| Телефон | `TEL_1` | Regex |
| Email | `EMAIL_1` | Regex |
| SWIFT | `SWIFT_1` | Regex |

**Поддерживаемые форматы:** TXT · DOCX · PDF (только с текстовым слоем) · XLSX · RTF

## Быстрый старт (разработчику / продвинутому пользователю)

```bash
# 1. Создать виртуальное окружение (рекомендуется)
python -m venv .venv
source .venv/bin/activate        # macOS/Linux
.venv\Scripts\activate           # Windows

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить
python app.py
```

Браузер откроется автоматически на `http://127.0.0.1:5000`.

> **Первый запуск:** библиотека Natasha скачает языковую модель (~220 МБ) в папку `~/.natasha`.
> Это происходит один раз. Пока модель загружается, структурированные данные
> (ИНН, телефоны, email и т.д.) уже обрабатываются.

## Сборка в исполняемый файл

### Windows → `.exe`

```bat
build_windows.bat
```

Результат: `dist\Anonymizer.exe` — один файл, без установки Python.

### macOS → бинарник / `.app`

```bash
chmod +x build_macos.sh
./build_macos.sh
```

Результат: `dist/Anonymizer` (или `dist/Anonymizer.app`).

> При первом запуске собранного файла на macOS может потребоваться:
> `xattr -cr dist/Anonymizer.app` и разрешение в «Системных настройках → Конфиденциальность».

## Как пользоваться

1. **Создайте сессию** — левая панель, кнопка «Новая сессия».
   Одна сессия = один документ или пакет связанных документов
   (один маппинг токенов для всех файлов в пакете).

2. **Выберите режим** — Анонимизация или Деанонимизация.

3. **Загрузите файлы** — перетащите или нажмите на зону загрузки.

4. **Нажмите «Обработать файлы»** — скачайте результаты по одному или ZIP-архивом.

5. **Таблица маппинга** показывает соответствие токен ↔ исходное значение.
   Используйте её, чтобы интерпретировать ответы ИИ, полученные на анонимизированный документ.

## Особенности и ограничения

### ФИО и склонения
Natasha нормализует ФИО в именительный падеж. При деанонимизации
восстанавливается именительный падеж (не оригинальный). Это ограничение v1.

### DOCX — форматирование
Если персональные данные попадают на стык двух «ранов» с разным форматированием,
при замене внутреннее форматирование этого фрагмента упрощается.
Форматирование остального абзаца и документа сохраняется.

### PDF — деанонимизация
На macOS и Windows приложение ищет системный шрифт с поддержкой кириллицы.
Если он найден — деанонимизация сохраняет PDF. Если нет — создаётся `.txt`-файл
с корректным текстом.

### RTF
Замена применяется к сырому RTF-содержимому. В большинстве случаев работает корректно.
Очень сложные RTF-файлы могут потерять часть форматирования.

## Структура файлов

```
anonymizer/
├── app.py              ← Flask-сервер, все маршруты
├── core/
│   ├── anonymizer.py   ← Regex + Natasha NER
│   ├── db.py           ← SQLite (сессии + маппинг)
│   └── handlers.py     ← Обработчики форматов
├── static/
│   └── index.html      ← Весь фронтенд (HTML+CSS+JS)
├── uploads/            ← Рабочая директория (создаётся автоматически)
├── anon.db             ← База данных (создаётся автоматически)
├── requirements.txt
├── build_windows.bat
└── build_macos.sh
```

---

## Данные и безопасность

- Всё хранится локально: `anon.db` и папка `uploads/`.
- Никаких внешних запросов, облака, телеметрии.
- Для удаления всех данных: удалите `anon.db` и папку `uploads/`.
