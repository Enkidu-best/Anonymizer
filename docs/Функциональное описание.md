## 1. Коротко

Anonymizer готовит документы к отправке во внешнюю нейросеть: находит персональные данные, банковскую и коммерческую тайну и заменяет их метками вида `[FIO_1]`, `ООО «[YUL_2]»`, `[INN_3]`. Ответ внешней нейросети загружается обратно - метки заменяются исходными значениями (с подбором падежа ФИО в новом тексте). Всё работает на компьютере: внешних служб нет, нейросеть (если включена) - локальная, через Ollama. Для юриста, который работает с договорами, выписками, сканами.

Главные сценарии:
- **Обезличить и отправить:** «+ Новая сессия» → перетащить файлы → «Быстро» / «Точно» → «Обработать» → «Просмотр» (проверить, поправить) → «Скачать» → «Скопируйте фразу» (инструкция для внешней нейросети).
- **Вернуть данные в ответ нейросети:** та же сессия → «Деанонимизация» → загрузить ответ → «Обработать» → «Просмотр» (зелёным - точно, жёлтым - падеж подобран, красным - метка не найдена) → «Скачать».
- **Поправить найденное:** «Таблица замен» или правая панель «Просмотра» → изменить, добавить, «Не маскировать», объединить дубли → файл пересобирается сам.

Главная метрика (из `CLAUDE.md`) - полнота: пропущенное имя уходит за рубеж, лишняя маска лишь немного мешает анализу.

## 4. Сквозные правила

- **Язык окна:** только русский; язык документа не меняется (поиск рассчитан на русские документы, латиница в ФИО поддерживается).
- **Тема и масштаб:** только тёмная тема; лист документа в просмотре - светлый; масштаба нет.
- **Видеокарта:** запросы к нейросети - под общим замком `.heavy-lock` (`core/heavy.py`, общий модуль `common/lock` 1.3.1, без своей копии логики); «Точно» и «Только нейросеть» - владелец «человек» с окном выбора (3.11); прогрев при запуске - «фон», при занятой видеокарте пропускается; падежи при восстановлении - ждут до 60 с, потом без нейросети. `ANONYMIZER_HEAVY_LOCK_HELD=1` - замок уже держит запустивший (прогоны).
- **Хранение данных** (`app.py:27-54`): `.app` - `~/Library/Application Support/Anonymizer` (Windows - `%APPDATA%\Anonymizer`), из исходников - папка проекта; `ANONYMIZER_DATA_DIR` - своя папка (тесты). Там: `anon.db`, `uploads/<сессия>/input|output|restore_marks|manifest.json`, `settings.json`. Оригиналы старше 30 дней (`ANONYMIZER_RETENTION_DAYS`) удаляются при запуске.
- **Удаление:** сессия, файл - безвозвратно (Р-14); запись замены - никогда не удаляется, а уходит в архив («не маскировать» / «заменена»), чтобы восстанавливались прежние файлы.
- **Экспорт / импорт:** «Скачать», «PDF», «Скачать все (ZIP)»; импорта сессий и таблиц замен нет.
- **Безопасность:** сервер слушает только `127.0.0.1`; запросы с чужим адресом, чужим Origin и межсайтовые отклоняются (`app.py:117-134`); путь в имени файла запрещён.

## 5. Модели и данные

- **spaCy `ru_core_news_lg`** (имена и организации, ~500 МБ, в комплекте) - загружается в фоне при каждом запуске (`app.py:101-102`); не загрузилась - «Быстро» работает без неё (Р-13).
- **pymorphy3** - морфология ФИО и лемм; словари OpenCorpora.
- **Ollama, модель по умолчанию `qwen3.5:9b`** (`core/llm.py:20`), адрес `localhost:11434`. Когда нужна: «Точно» (фоновая проверка списка найденного и подозрительных строк, `core/llm_review.py`), «Только нейросеть» (весь текст фрагментами по ~3 000 знаков, `core/llm.py:334`), падежи при восстановлении. Загружается: прогрев при запуске, если видеокарта свободна; держится 30 мин после запроса (`keep_alive`); «На процессоре» - без видеокарты (`num_gpu: 0`) и выгружается сразу. Без модели: «Быстро» - полностью; «Точно» - файл после правил и «Нейросеть недоступна…»; «Только нейросеть» - молча почти пустой результат (Р-12); восстановление - падежи только правилами.
- **Apple Vision** - распознавание сканов и фото (только macOS); **pdf2docx** - PDF с текстом → Word; **textutil / LibreOffice** - DOC, ODT → DOCX; **docx-preview, JSZip** - просмотр Word в окне.
- **Форматы** (README, `core/handlers.py`):

| Формат | Что проверяется | Результат |
|---|---|---|
| DOCX, DOCM, DOC, ODT | текст, таблицы, надписи, колонтитулы, сноски, комментарии, исправления (принимаются), ссылки, свойства | DOCX; DOC / ODT - сначала в DOCX |
| PPTX | слайды, заметки, диаграммы | PPTX (просмотра нет) |
| XLSX, XLSM | ячейки, в т. ч. числа, комментарии, названия листов, колонтитулы, свойства | XLSX |
| PDF с текстом | как Word (по умолчанию) | DOCX (+ PDF по настройке) |
| PDF-скан | распознавание, чёрные плашки с меткой; испорченный текстовый слой распознаётся заново | PDF |
| RTF | текст в любой кодировке | RTF |
| JPG, PNG, HEIC, TIFF | распознавание, закраска, без EXIF / GPS | то же (HEIC → PNG); необратимо |
| TXT | текст | TXT |

- **Что находит:** ФИО во всех падежах и формах, организации (ОПФ остаётся в тексте), ИНН, ОГРН / ОГРНИП, КПП, счета, БИК, карты, IBAN, SWIFT, СНИЛС, паспорт, водительское удостоверение, телефоны, e-mail, ники, даты и места рождения, адреса, кадастровые номера, записи ЕГРН, госномера, VIN, ОКПО, полисы ОМС, реестровые номера нотариусов. Не маскируются: роли сторон, должности, заголовки, госорганы (`core/lexicon.py`). Правила по видам - `docs/PII_VARIANTS_CATALOG.md`.
- **Одна сущность - одна метка:** «Петров Иван Сергеевич», «Петрову И.С.», «Петров» в подписи - `[FIO_1]`; в конце обработки база проверяется и дубли объединяются (номера - только при совпадении цифр); спорные пары - человеку («Проверка дублей»).
- **База `anon.db`:** `sessions`, `mappings` (метка, форма в документе, форма для нового текста, тип, статус, ОПФ), `places` и `place_forms` (отпечаток абзаца → формы, для точного восстановления), `occurrences`, `token_aliases`, `distinct_pairs`, `exclusions`, `known_entities` (глобальная память, Р-24), пользовательские шаблоны (`/api/patterns`, без окна). Схема поднимается на месте `ALTER TABLE` (`core/db.py:72-138`).

## 6. Чего нет и почему

Сознательно (по README и CHANGELOG):
- **Облака и внешних служб** - всё на компьютере; данные не уходят.
- **Восстановления изображений и сканов** - закрашенное необратимо; скан восстанавливается вписыванием значения в плашку.
- **Просмотра презентаций** - слайды в окне нечитаемы, только «Скачать».
- **Распознавания сканов и фото на Windows** - Apple Vision есть только на macOS.
- **Word через AppleScript для PDF** - отвергнут в 3.4.0 (диалоги, зависание, обращение к рабочему Word); выбран pdf2docx.
- **Обязательной нейросети** - «Быстро» по умолчанию; «Точно» - по желанию: польза проверки на замерах около нуля (3.4.0).
- **Снятия маски нейросетью с адресов с географическими словами и с номеров с контрольной суммой** - защита от ошибок модели.

Нет без решения (это разрывы, см. 3.15): Справка, RU / EN, тема, «Aa», корзина, поиск и переименование сессий, «Остановить», возврат из архива записей, просмотр и очистка глобальной памяти.
