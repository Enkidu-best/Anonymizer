# Anonymizer - продукт

Версия 1 · 24.10.2026 · задание 01 (ревью дизайн-чата). Основа: «Функциональное описание.md» v1 «как есть», README,
CHANGELOG 3.4.2.

## Зачем

Юристу удобно отдать договор, выписку или претензию внешней нейросети (ChatGPT, Claude): разобрать, сравнить,
написать ответ. Но в документе - персональные данные, банковская и коммерческая тайна, их нельзя отправлять за рубеж
(152-ФЗ, банковская тайна). Anonymizer заменяет такие значения метками (`[FIO_1]`, `ООО «[YUL_2]»`, `[INN_3]`),
а в ответ нейросети возвращает исходные значения - с нужным падежом ФИО. Всё работает на компьютере, ничего не
уходит в интернет.

## Для кого

- **Юрист банка или компании** - работает с договорами, выписками ЕГРЮЛ, доверенностями, сканами и хочет пользоваться
  внешней нейросетью, не раскрывая данных.
- **Демо и портфолио Андрея** - обратимое обезличивание русских юридических документов: полнота на стенде, проверка
  утечек, точный возврат.

## Главные сценарии

1. **Обезличить и отправить.** Пользователь хочет отдать документы нейросети → «Обезличить», перетаскивает файлы,
   нажимает «Обезличить» → получает файлы с метками, итог проверки утечек и короткую инструкцию для нейросети, чтобы
   она не трогала метки. Один человек во всех файлах сессии - одна метка.
2. **Вернуть данные в ответ нейросети.** Хочет получить готовый документ с настоящими именами → «Вернуть данные»,
   загружает ответ нейросети → получает файл, где метки заменены значениями; места с подобранным падежом
   подсвечены, ненайденные метки названы.
3. **Поправить найденное.** Видит лишнюю или пропущенную маску → «Просмотр» → «Не маскировать», «Замаскировать»
   выделенное, «Изменить» → файл пересобирается сам. Значение, которое нужно маскировать или не маскировать всегда,
   уходит в «Словарь» - его видно и можно удалить.

## Что программа не делает

- Не отправляет документы и значения в интернет; нейросеть, если включена, - локальная.
- Не гарантирует 100 %: перед отправкой файл нужно просмотреть (программа показывает итог проверки утечек).
- Не восстанавливает сканы и фото: закрашенное необратимо.
- Не хранит данные дольше нужного: сессия удаляется целиком через срок из Настроек (по умолчанию 30 дней) или сразу
  по кнопке, без корзины.
- Не проверяет юридическую суть документа и ответ нейросети.

## Метрика успеха

- **Полнота** - главная: пропущенное имя уходит за рубеж, лишняя маска лишь немного мешает. Стенд 245 вариантов -
  не ниже 99 % (сейчас 99 %); ложных срабатываний (FP) и ошибок возврата (RT) - 0.
- **Проверка утечек** - 0 исходных значений в готовом файле (перечитывается независимым кодом).
- **Возврат** - каждая метка ответа вернулась или названа как «не найдена»; падеж ФИО в новом тексте - по правилам,
  спорные места подсвечены.
- **Время** - договор 10 страниц обезличивается за секунды.
