## Практика

- **Обратимое обезличивание** - тот же принцип, что Microsoft Presidio: распознаватели (правила, словари, NER) находят значения → операторы заменяют их метками → таблица соответствий позволяет вернуть исходное (LangChain `PresidioReversibleAnonymizer`). Наш путь (правила + spaCy/Natasha + проверка утечек) - правильный; нейросеть - необязательный распознаватель, а не режим работы.
- **Минимизация данных**: персональные данные хранятся не дольше, чем нужно для цели (152-ФЗ, ст. 5 ч. 7; GDPR, ст. 5(1)(e)). Таблица соответствий и оригиналы - самое чувствительное, что есть в программе.
- Общий стандарт: «Единый стандарт программ» 1.x (каркас, тема, RU/EN, 17 px и «Aa», узкое окно), 2.1-2.5 (состояние модели, долгие операции, очередь видеокарты), 3.x (списки, удаление, окна подтверждения), 4.x (Настройки), 5 (Справка), 6.x (запуск `.app` общим сборщиком, `/api/info`, фиксированный порт, данные в `platformdirs`, проверки).

### 1. Каркас - общий (Р-1…Р-6, Р-29, Р-30, Р-32…Р-35)
Меню слева: **«Обезличить»**, **«Вернуть данные»**, **«Сессии»**, **«Словарь»**; внизу - Справка, Настройки, Тема, версия. Шапка: «← Назад» и путь, одна строка состояния модели (2.1), RU | EN, «Aa». Слова окна - без spaCy, LLM, Ollama, маппинг, токен, плейсхолдер: «модель», «запись», «метка»; режимы - «Обезличить» / «Вернуть данные» (не «Анонимизация / Деанонимизация / восстановление»).

### 2. Один режим обработки вместо трёх (вопрос 4, Р-9…Р-12)
По замерам 3.4.0 польза проверки нейросетью около нуля. **Один режим «Обезличить»** (правила + NER + проверка утечек); **«Проверить ещё нейросетью»** - галочка в Настройках → «Дополнительно» (по умолчанию выключена; если включена - под очередью видеокарты с окном 2.4, «Остановить» и «в очереди»). «Только нейросеть» - из окна убрать, оставить командой для замеров качества (`scripts/`).

### 3. Таблица замен и просмотр - одно действие одним словом (Р-19…Р-23, Р-25, Р-27)
- Убрать с маски - везде одно слово **«Не маскировать»**, одно окно подтверждения программы (не `confirm()`), «Вернуть» в строке 5 с и в фильтре **«Не маскируется»** таблицы (вместо архива с неработающим путём).
- Фильтр - все виды записей (30), не 17.
- «+ Добавить вручную» - доступна всегда, до обработки - «добавится и применится при обработке».
- Предложения нейросети: «Снять маску» **по умолчанию не отмечено** (метрика - полнота) - ответ на вопрос 5.
- Окна - Esc закрывает, Enter подтверждает, щелчок мимо закрывает.

### 4. Словарь (глобальная память) - видимый и управляемый (вопрос 2, Р-24)
Раздел меню **«Словарь»**: «Всегда маскировать» (значения, которые программа маскирует во всех сессиях) и «Никогда не маскировать» - списком с поиском и удалением. При ручном добавлении или «Не маскировать» - выбор «только в этой сессии / всегда» (по умолчанию - только в этой сессии).

### 5. Сессии и хранение - минимизация данных (вопросы 3, 6, Р-14…Р-18, Р-38…Р-40)
- **Удаление сессии - сразу и безвозвратно**, с окном подтверждения: «Удалятся оригиналы, обезличенные файлы и таблица соответствий. Вернуть данные в ответ нейросети после этого будет нельзя». Это осознанное исключение из стандарта 3.2 (корзина) - **записать в стандарт**: «данные с персональными сведениями - без корзины».
- Срок хранения - в Настройках (по умолчанию 30 дней), удаляется **вся сессия целиком**, а не только папка файлов; за 3 дня - пометка в списке «удалится через 3 дня».
- **Имя сессии - не из имени файла** (там бывают фамилии): «Сессия 24.10 · 3 файла», переименование вручную («⋯ → Переименовать»).
- Список сессий - поиск, «⋯» у строки, число файлов и записей одним понятием.
- Повторное открытие - итоги (объектов, проверка утечек) из базы, восстановленные файлы - в «Вернуть данные»; ZIP - только файлы своего раздела.

### 6. Долгие операции и состояния (Р-8, Р-13, Р-26, Р-41, Р-42)
